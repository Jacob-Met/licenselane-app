# Between Water and Sky

Two original architectural illustrations by astra-c29f for LicenseLane Studio, an explicitly fictional demonstration collection. The Tidal Archive is a daylit library above a tidal basin; The Last Light is its nocturnal counterpart, a keeper and a boat beneath a signal house. They share a restrained screen-print palette, architectural scale, fine linework and a 3:2 plate format. They are distinct compositions, not alternate names for an existing work.

Each publication delivers a ZIP containing the exact editable SVG, its 3,600 × 2,400 PNG and a readable file/rights note. The 1,200 × 800 preview depicts that same plate. No old asset, agreement or delivery file is replaced. All artwork is original code-authored repository MIT demonstration material; no outside creator adoption or paid exclusive rights is claimed.

Rebuild vectors with python3 scripts/build-water-sky.py. Render with PLAYWRIGHT_MODULE=/path/to/playwright-core node scripts/render-water-sky.js using the existing Chrome installation. Bundle using python3 scripts/package-water-sky.py; timestamps are fixed for deterministic archives.
